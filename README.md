# S-Salam Portfolio

Simple white React + TypeScript portfolio with three navigation areas:

- Home
- Portfolio
- Contact

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Edit your content

Main content: `src/App.tsx`

Main styling: `src/App.css`

Replace `your-email@example.com` with your email address and replace the project placeholders with your own project images/screenshots when ready.
